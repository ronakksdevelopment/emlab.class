    About EMlab Classes

    EMlab Classes Version 1.0 Beta, by English Mastery Lab.

    This beta runs entirely in your browser with no backend server. Profiles, classes, and classroom data are stored locally on this device using your browser's storage.

    Honest limitation: camera and microphone previews, chat, and file sharing work locally for demonstration, but this beta does not transmit real time audio or video between separate devices, and does not sync data across devices. Genuine multi device video calls and live sync require a signaling and backend server planned for a future release.

    Install this app to your device for quick access and offline use of the interface.
